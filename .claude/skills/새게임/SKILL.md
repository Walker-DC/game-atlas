# /새게임 — 게임 등록과 APK 추출

입력: $ARGUMENTS

## 1. 폴더 만들기
- `게임/<게임이름>/`을 만든다. 하위 폴더는 `apk/`, `추출/`, `자료/`, `결과/`.
- 이미 있으면 덮어쓰지 말고 사용자에게 확인한다.
- Windows 경로(`C:\...`)는 `/mnt/c/...`로 바꿔 읽는다.
- APK·XAPK·APKS·OBB 원본은 `apk/`에 **복사**한다. 원본 위치의 파일은 건드리지 않는다.

## 2. APK 추출
```bash
python3 도구/apk_추출.py 게임/<이름>/apk/<파일들> 게임/<이름>/추출
```
- 결과의 엔진이 Unity이고 UnityPy가 없으면, 설치해도 되는지 사용자에게 묻는다. 허락하면 `python3 -m pip install --user UnityPy`로 설치하고 다시 돌린다.
- `추출/요약.md`를 읽고 사용자에게 짧게 보고한다.
  - 엔진, 패키지, SDK
  - 읽힌 데이터 양
  - 시스템 키워드 상위
  - 암호화 추정 파일 수
- 키워드가 거의 0이거나 데이터가 적으면 분명히 말한다. 리소스를 설치 후 내려받는 구조일 수 있으니, 설치된 기기의 `Android/data/<패키지>/`나 OBB를 받으면 더 읽을 수 있다고 안내한다.

## 3. 설정.json
`게임/_템플릿/설정.json`을 복사해 채운다.
- **자동으로 채울 것**: `name`, 추출본에서 알 수 있는 `background`(엔진·패키지).
- **원작 판별**: 추출본의 외국어 로고 이미지·외국어 문자열·판호/ISBN·저작권자·CDN 경로를 확인해 다른 나라 원작으로 보이면 `origin`(원작명 원문 표기, 국가, 개발사, 근거)을 채우고 사용자에게 보고한다. 국내 개발이면 `origin`은 비운다.
- **사용자에게 물어서 채울 것**(한 번에 묶어서 묻는다):
  - `purpose`
  - `goal`: 기본값은 매출
  - `benchmark.genre`: 비우면 에이전트가 판정
  - `submission`: 개발사 제출안이 있으면 `자료/`에 텍스트로 옮기고 `{"file":"자료/제출안.txt","label":"개발사 제출안","prefix":"D"}`로 넣는다.
  - `materials`: 사내 매출 자료·커뮤니티 덤프 경로
- 사용자가 준 추가 자료는 `자료/`에 복사하고 `materials`에 경로와 용도를 적는다. 사내 원본은 읽기 전용이다.
- 매출 자료가 없으면 `background`에 "사내 매출 자료 없음 — 지표는 외부 추정"이라고 적는다.

## 4. 기록
- `CLAUDE.md`의 "등록된 게임" 표에 한 줄을 추가한다(게임, 등록일, 엔진, 추출 상태, 매출 자료 유무).
- 마지막에 다음 단계로 `/분석 <게임이름> <지시>`를 안내한다.
